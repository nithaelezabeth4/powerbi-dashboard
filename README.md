# HR Analytics Dashboard
This project presents an interactive HR Analytics dashboard built using Microsoft Power BI to analyze employee data and uncover key workforce insights.
# Overview
The dashboard focuses on analyzing employee trends such as:
Employee count and distribution
Attrition (employee turnover)
Department-wise performance
Job roles and salary insights
Experience and age distribution
It helps HR teams understand workforce behavior and make better decisions.
 # Features
Interactive filters (Department, Gender, Job Role)
Attrition analysis and trends
KPI cards (Total Employees, Attrition Rate, Avg Salary)
Visual comparison across departments
Clean and intuitive design
# Tools & Technologies
Power BI
Microsoft Excel (Dataset)
Data Cleaning & Transformation
